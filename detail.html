Doconnect – neue Website

coding wcag performance

von Stephan Fössl

Demo-Bild

Doconnect bekommt eine runderneuerte Website. Ausgangspunkt war der Anspruch, dass eine digitale Anlaufstelle im Gesundheitsbereich nicht nur gut aussehen, sondern für wirklich alle nutzbar sein muss — unabhängig von Sehschärfe, motorischen Einschränkungen oder verwendeter Hilfstechnologie.

Im Zuge des Relaunches wurde die Seite auf WCAG‑AAA‑Konformität hin überarbeitet: klare Kontraste, durchgängige Tastaturbedienbarkeit, sinnvolle Sprungmarken und eine Struktur, die auch mit Screenreadern verständlich bleibt. Parallel dazu wurde der Code schlanker — weniger Ballast, spürbar schnellere Ladezeiten, sauberere Auslieferung.

Das Ergebnis ist eine Website, die sich leiser anfühlt als vorher: weniger visuelles Rauschen, mehr Klarheit an den Stellen, die für Patient:innen wirklich zählen.
